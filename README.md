# 🧩 Collection of Problems

Архив решённых задач и упражнений, накопленных в процессе обучения и практики программирования. Репозиторий служит личной базой знаний: здесь фиксируются подходы к решению разных типов задач и методологии разработки, к которым удобно возвращаться и на которые можно ссылаться в будущих проектах.

## 📖 Источник задач

Задачи взяты из учебного сборника:

> **«Сборник задач по предмету "Программные средства создания Internet-приложений" (ПСС)»**
> Частное учреждение образования «Колледж бизнеса и права»

📄 [Открыть сборник задач (PDF)](https://github.com/Avent-a/collection-of-problems/files/14323068/default.pdf)

Задания охватывают вёрстку статичных страниц (заголовки, теги форматирования текста), адаптивную и фиксированную раскладку на CSS, а затем логику и интерактивность на JavaScript, jQuery и PHP — от простых циклов и работы с массивами до обработчиков событий, форм и работы с DOM.

## 🎯 Цель репозитория

- Хранить решения задач в одном месте, а не разбрасывать их по разным черновикам
- Отслеживать прогресс и рост в разных языках/темах
- Иметь под рукой рабочие примеры и шаблоны для повторного использования

## 📂 Структура

```
collection-of-problems/
├── ...              # Задачи сгруппированы по номерам / темам из сборника
```

> Структура папок отражает нумерацию и тематику задач из сборника (HTML-разметка → CSS-раскладка → JavaScript/jQuery → PHP) — по мере роста репозитория состав может меняться.

## 🛠️ Как пользоваться

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sollcoun/collection-of-problems.git
   ```
2. Перейдите в интересующую папку с задачей.
3. Изучите решение и (при наличии) комментарии в коде — они объясняют ход мысли, а не только финальный ответ.

## 📈 Прогресс

Репозиторий пополняется по мере решения новых задач. Каждая добавленная работа — это либо новая тема из сборника, либо более удачное решение уже знакомой задачи.
